How a payment is confirmed

  1. Order created on the server with the exact amount due.
  2. Parent pays in the app or through the payment link.
  3. Verified gateway webhook (or status check) marks it paid; a repeated webhook never creates a second receipt.
  4. Receipt and ledger entry are posted together; settlement is matched the next morning.
